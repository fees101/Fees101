02 — COLOUR, ONE JOB EACH

Three hues. Everything else is ink.

Signal red

#EC3013 · text #AE1800

Mark, structural rules, collection bars, destructive confirm. Never a row status, never the default button.

Ledger green

#0A6B3D · on ink #35C483

Money that arrived. Amounts paid, settled rows, collected totals, receipts.

Ochre

#B45F06 · text #8A4805

Needs follow-up. Overdue, partial, pending, expiring, dormant.

Ink

#201E1D · 2 #444141 · 3 #605D5D · dim #9B9797

Everything else. Rules, type, the default button.

Red text under 20px MUST be #AE1800 (6.4:1). Ochre text MUST be #8A4805. Rules: 2px #201E1D structural · 1px #D7D3D3 between rows · 1px rgba(32,30,29,.4) cell borders.

06 — THE ONLY LOADING STATE

A sweeping rule. Never a spinner.

.loading-rule { position: relative; height: 2px; background: #d7d3d3; overflow: hidden; } .loading-rule::after { content:''; position:absolute; inset:0 auto 0 0; width:30%; background:#ec3013; animation: sweepRule 1200ms linear infinite; }

No spinners, no skeleton cards, no shimmer. A page that is loading shows its rules and its headings with the sweep under the section that is waiting.
