Supabase Auth email templates — paste into the Supabase dashboard
(Authentication → Emails → Templates), one per template.

Modernist palette, matching the redesigned app: paper ground (#f3f2f2),
ink text and header band (#201e1d), a single signal-red accent (#ec3013)
for the rule under the header, the primary button, and the "101" mark.
Flat surfaces only — a 2px ink border on the card, no rounded corners, no
box-shadow, no mint, no navy. The footer mark is "Fees101" (the 101 in
signal red); the old "Powered by Fees101" branding line is dropped.
Web fonts don't load reliably in email clients, so the stack prefers
Archivo but falls back to Helvetica/Arial. Kept generic on purpose (no
per-school logo) — per the decision to keep Supabase's native send.

Password changed / Email address changed are separate "notification emails"
(Authentication → Emails, own Enable toggle) that fire automatically
whenever the corresponding auth.users field changes — self-service or
admin-triggered (e.g. via admin.auth.admin.updateUserById) — no app code
needed to send them.
