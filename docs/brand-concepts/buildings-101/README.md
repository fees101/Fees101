# Brand concept: "101" as structured records (buildings execution)

Archived 2026-09-30. Not live — the site currently uses the earlier ledger/
document mark (`fees101-marketing/public/brand/`). This is saved here in case
the concept gets refined and picked up later.

## The idea

Three vertical forms read as "1-0-1": the centre form carries horizontal
ledger/accounting lines standing in for the "0", the outer two are the "1"s.
The red panel marks the one outstanding/active item among otherwise orderly
records. Intent: an abstract, ownable mark (like Stripe or Linear's marks
don't depict payments/issues literally) rather than another literal
receipt/book/checkmark icon — those are common tropes and harder to make
distinctively Fees101's own.

## Known problem, not yet fixed

Current execution reads as an office building/skyline before it reads as
"101" — the pitched roof shapes on the outer forms are the cause. A mark that
needs the explanation above to be understood hasn't earned its abstraction
yet. Agreed next-iteration fix list (not done in this crop pass — these files
are a straight crop of the sheet as generated):

- Flat-topped vertical forms, no roof/pitch cues at all.
- Centre form keeps the horizontal ledger rules (the "0").
- Signal red (`#ec3013`) on **one structural element only** — e.g. a single
  ledger line or accent, not a whole third panel. Matches the rest of the
  product's rule that signal-red is a sparing accent, never a dominant fill.
- Keep `#201e1d` (ink) dominant.
- Wordmark stays plain Archivo — let the icon carry the distinctiveness.
- Test the mark at 16×16, 24×24, 32×32 before calling it done — favicon
  legibility is the real bar, not how it looks at poster size.
- Negative-space reinforcement of "101" between the forms is a nice-to-have,
  not a must-have — treat it as a bonus if it falls out naturally, not a
  blocker on shipping the rest of the fixes.
